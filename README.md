# Delivery App prototype

A clickable prototype of two screens from the Figma **Delivery App UI Kit (Community)**, styled with the Groceries design system:

- **Categories** (`index.html`): category grid with live search.
- **Vegetables** (`vegetables.html`): category chips, products with favorite and add-to-cart buttons; the cart count on the tab bar is shared across screens.

Plain HTML, CSS and JavaScript: no build step. Open `index.html` in a browser, or publish the folder with GitHub Pages.

## Adding the photos

The photo slots are grey placeholders. To use real images, add them to an `images/` folder and set the `image` field for each category in `index.html` and each product in `vegetables.html`, for example `image: 'images/vegetables.jpg'`.

## Before you publish

The screens are based on a Figma Community UI kit. Check the kit's license (and the license of any photos you add) before publishing them in a public repository.
